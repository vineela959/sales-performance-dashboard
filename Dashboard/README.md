# 📊 Sales Performance Dashboard

## 📌 Project Overview

This project analyzes sales performance using Excel, SQL, and Power BI. The dashboard provides key business insights such as total sales, total profit, regional performance, category-wise sales, and customer segment distribution.

---

## 🛠️ Tools Used

- Microsoft Excel
- MySQL
- Power BI

---

## 📂 Dataset

- Original Dataset (Excel)
- Cleaned Dataset (Excel)
- CSV Dataset

---

## 📈 Dashboard KPIs

- Total Sales
- Total Profit
- Sales by Region
- Profit by Region
- Sales by Category
- Sales by Segment

---

## 🔍 SQL Analysis

The following SQL concepts were used:

- SELECT
- COUNT()
- SUM()
- ROUND()
- GROUP BY
- ORDER BY
- LIMIT

- West region generated the highest profit.
- Technology category contributed the most sales.
- Consumer segment contributed more than 50% of total sales.
